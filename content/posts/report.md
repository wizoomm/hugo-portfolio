## Вывод

- Для HTTP-запросов нужно указывать заголовок `Host` и пустую строку между заголовками и телом запроса.
- При обращении по HTTP сервер `placebear.com` возвращает `301 Moved Permanently` — перенаправление на HTTPS.
- Через `openssl` удалось получить успешный ответ `200 OK`.
- Команда `curl` позволила сохранить изображение и проверить его наличие.
- В Postman выполнен GET-запрос к API Банка России, получен XML с курсом валют за указанный период.
